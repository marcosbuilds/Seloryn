# Seloryn Language for VS Code 0.8.0

This local candidate follows language `0.08` and runtime package `0.8.0`. It
adds completion entries for `as_i64_list` and `as_f64_list`, the editor-facing
surface of the typed JSON-array ingestion gain. The package also retains the
canonical Seloryn symbol, `.sely` association, CLI diagnostics and the initial
runtime LSP foundation. The VS Code LSP client is released separately as
`0.8.1` because it is an extension-only gain.

The VSIX is still a verified-preview candidate. It has not been published as
a Marketplace or GitHub release in this workspace turn.
