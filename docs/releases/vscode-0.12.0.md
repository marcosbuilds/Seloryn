# Seloryn VS Code extension 0.12.0 / language 0.12

This extension line follows the generic self-hosted language-model gain. Its
completions and syntax grammar expose fused cross-entropy and the runtime-sized
modular `.sely` workflow with reusable parameter and optimizer modules.

The package is published as the
[`vscode-v0.12.0`](https://github.com/marcosbuilds/Seloryn/releases/tag/vscode-v0.12.0)
verified-preview release asset. It is not a Marketplace publication and does
not change the runtime ABI. The extension builder source is outside the public
language repository; the downloaded VSIX remains inspectable executable
content.
