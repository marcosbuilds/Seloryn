# Seloryn Language for VS Code 0.9.0

This extension candidate follows language `0.09` and runtime package `0.9.0`.
It adds completion and a snippet for `training.predict_mlp`, the verified
bounded CPU MLP checkpoint batch-inference workflow. The canonical Seloryn
symbol, `.sely` association, parser-backed LSP client and CLI fallback remain
included.

The VSIX is a local verified-preview candidate. It has not been published as a
Marketplace or GitHub release in this workspace turn.
